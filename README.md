# ☕ Cafetería

Sistema de pedidos para cafetería desarrollado en Java aplicando Programación Orientada a Objetos, patrones de diseño y comunicación cliente-servidor mediante sockets.

---

## Conceptos y arquitectura implementada

- Programación Orientada a Objetos (POO)
- Arquitectura Cliente-Servidor
- Manejo de múltiples pantallas sincronizadas
- Comunicación en tiempo real mediante sockets
- Manejo de hilos (Threads)
- Temporizadores y concurrencia

---

## Patrones de diseño utilizados

### Decorator
Decoración dinámica de bebidas y productos adicionales.

### Factory
Creación centralizada de productos y bebidas.

### Composite
Construcción de combos y órdenes compuestas.

### Prototype
Clonación de combos predefinidos.

### Observer
Actualización automática de pantallas de cocina y despacho.

---

## Funcionalidades principales

- Gestión de pedidos
- Sistema de combos
- Personalización dinámica de bebidas
- Pantallas de cocina en tiempo real
- Confirmación y despacho de órdenes
- Timer de preparación por pedido
- Comunicación entre cliente y servidor

---

## How to Run

1. Open the project in NetBeans.
2. Run the main application file: Mainpackage/main.java
